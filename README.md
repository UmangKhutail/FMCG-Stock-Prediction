# FMCG Stock Prediction Dashboard

## About the Project
This project predicts next month's FMCG product sales using Machine Learning and helps manage inventory efficiently.

## Features
- Monthly sales data input
- Sales prediction using Linear Regression
- Average sales calculation
- Safety stock calculation
- Stock requirement and order quantity recommendation
- Sales visualization using Matplotlib
- SQLite database for saving records
- Interactive dashboard using Streamlit

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- SQLite

## Installation

Install the required libraries:

```bash
pip install streamlit pandas numpy matplotlib scikit-learn
```

## Run the Project

```bash
python -m streamlit run Python_Project.py
```

## Purpose
The project helps FMCG businesses forecast demand, reduce stock shortages, and make better inventory decisions.
